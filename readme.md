# jino-business-card-local-editor

> **Язык:** Русский · [English](readme.en.md)

Локальный редактор визитки Jino (jino.ru). Заточен под визитку сайта [mr712.ru](https://mr712.ru/), но работает с любой визиткой Jino — при первом запуске достаточно указать адрес сайта, и контент скачается автоматически. Прямого доступа к файлам сервера нет, поэтому репозиторий хранит редактируемую копию контента (`body.txt`) и мини-сервер предпросмотра (`start-preview.bat`), который показывает правки в браузере сразу после сохранения файла.

## Требования

- Windows 10/11
- Встроенный Windows PowerShell 5.1+ (ничего устанавливать не нужно)
- Любой браузер
- Интернет — нужен для первого импорта контента и для рендера предпросмотра

## Установка

1. Скопируйте папку репозитория в любое место (например, `E:\GitHub\jino-business-card-local-editor`)
2. Готово — установка завершена

`body.txt` создавать не нужно: при первом запуске редактор сам попросит адрес вашей визитки и скачает контент с сайта. Если `body.txt` уже лежит рядом с `start-preview.bat`, запрос не появится.

## Быстрый старт

### 1. Запустите предпросмотр

Двойной клик по `start-preview.bat`:

- **Первый запуск** (нет `body.txt`) — введите адрес визитки, например `https://mr712.ru`. Скрипт скачает страницу и создаст `body.txt` (контент) + `card.json` (настройки оформления: фон, цвет текста и т.д.)
- **Последующие запуски** — сразу поднимается сервер и открывается браузер на `http://127.0.0.1:8077/`

```
==============================
Preview server : http://127.0.0.1:8077/
Source file    : E:\GitHub\...\body.txt
Render         : real businesscard.js (like production)
Edit body.txt  -> page reloads automatically
Re-sync        : run start-preview.bat with site URL as argument
Stop           -> Ctrl+C or close this window
==============================
```

Запускать можно любым способом: двойной клик, запуск из cmd или через PowerShell («Выполнить с помощью PowerShell» тоже работает — файл является полиглотом bat+ps1). Остановить сервер можно не только Ctrl+C или закрытием окна консоли, но и двойным кликом по `stop-preview.bat`.

### 2. Редактируйте body.txt

Откройте `body.txt` в любом редакторе и меняйте HTML. Вкладка браузера отреагирует **мгновенно** — опрос каждые полсекунды плюс проверка при переключении на вкладку; F5 нажимать не нужно.

> Правка `body.txt` **не меняет живой сайт** — это локальная копия контента.
>
> Обычный запуск `start-preview.bat` (без аргументов) **никогда не перезаписывает** существующий `body.txt` — он работает с ним как есть. Перезапись происходит только при явном ре-синке с адресом сайта в аргументе (и предыдущая версия сохраняется в `body.txt.bak`).

### 3. Опубликуйте изменения

1. Откройте панель управления [jino.ru](https://jino.ru/)
2. Перейдите в раздел сайтов → визитка → редактор
3. Скопируйте содержимое `body.txt` в поле текста (HTML) и сохраните
4. Проверьте живой сайт

## Обновление контента с сайта (ре-синк)

Если визитку уже поменяли через панель Jino и нужно заново забрать контент:

```
start-preview.bat https://example.ru
```

Схема `https://` необязательна. Текущий `body.txt` перед перезаписью сохраняется как `body.txt.bak`. Локальные правки при этом затираются — используйте ре-синк осознанно. Вместе с `body.txt` обновляется и `card.json`.

### Про card.json

`card.json` создаётся скриптом автоматически (при первом импорте или ре-синке) и хранит оформление конкретного сайта: `bg_color`, `font_color`, `layout`, favicon и остальные поля `bcData`, кроме самого контента. Это служебный файл:

- он привязан к тому сайту, из которого сделан импорт, — у другого сайта будет другим;
- при каждом ре-синке перезаписывается;
- вручную его править не нужно;
- если удалить — превью продолжит работать со встроенными дефолтами (чёрный фон, белый текст).

## Как работает start-preview.bat

`start-preview.bat` — тонкий лаунчер, весь код сервера находится в `preview.ps1`.

| Компонент | Описание |
|-----------|----------|
| Порт | `127.0.0.1:8077` (если занят — автоматически берёт 8078–8099) |
| Сервер | Однопоточный TCP HTTP-сервер на `System.Net.Sockets.TcpListener`, без логов |
| Импорт | Первый запуск: адрес сайта запрашивается интерактивно или берётся из аргумента; из страницы извлекается `var bcData` → `text` идёт в `body.txt`, остальные поля — в `card.json` |
| `GET /` | Собирает **реплику продакшена** на лету: `<div id="root">` + инлайн `var bcData = {...}` (поля из `card.json` + текст из `body.txt`) + настоящий рендерер Jino `businesscard.js` — вид совпадает с оригиналом |
| `GET /~mtime` | Возвращает время последнего изменения `body.txt` (для автообновления) |
| Автообновление | JS на странице опрашивает `/~mtime` раз в 500 мс + при фокусе вкладки; если значение изменилось — `location.reload()` |

Для рендера нужен интернет (скрипт `businesscard.js` загружается с CDN Jino). Если CDN недоступен, сработает фолбэк — HTML вставится в страницу без обвязки рендерера.

Сервер ничего не пишет на диск, не изменяет `body.txt` и не создаёт временных файлов. Останов — Ctrl+C в консоли, закрытие окна или `stop-preview.bat`.

Переменная окружения `MR712_NO_BROWSER=1` подавляет автоматическое открытие браузера (удобно для автотестов).

## Как устроен сайт визитки на примере mr712.ru

Живая страница — статический каркас от Jino:

- `<html data-page="businesscard">` подключает `//parking-static.jino.ru/static/businesscard.js?1.45.0`
- В теле страницы: `<div id="root"></div>` и инлайн `<script> var bcData = {...}; </script>`
- `businesscard.js` рендерит поле `bcData.text` (весь HTML визитки одной JSON-строкой) внутрь `#root`
- Фон страницы — `bcData.bg_color` (#000000), favicon хранится на `media.jino.ru`

Состав контента визитки:

- Шапка: аватар (inline base64 JPEG ~142 КБ ≈ 96% веса страницы), заголовок **Mr712**, подпись «Тот самый»
- CSS-grid из 3 колонок с 6 карточками-ссылками: YouTube, Telegram, TikTok, Instagram, GitHub, 4PDA
- Футер: «Сайт оплачен до 29 мая 2028»
- Инлайн `<style>` с адаптивом: при ширине ≤600px сетка становится 2 колонки

# Файлы

| Файл | Описание |
|------|----------|
| `body.txt` | Контент визитки — главный редактируемый файл (HTML + inline-CSS) |
| `card.json` | Настройки оформления визитки (фон, цвет текста и т.д.), создаются при импорте с сайта; привязаны к сайту, см. «Про card.json» |
| `start-preview.bat` | Лаунчер сервера предпросмотра |
| `preview.ps1` | Код сервера предпросмотра + логика импорта/ре-синка |
| `stop-preview.bat` | Останавливает сервер предпросмотра (находит процессы PowerShell с `preview.ps1`) |
| `body.txt.bak` | Бэкап предыдущей версии контента (создаётся при ре-синке) |

## Ограничения формата визитки Jino

Контент вставляется в редактор Jino, поэтому:

- Только HTML + inline-стили; разрешён тег `<style>`
- Без внешних и inline скриптов
- Сохраняйте структуру: шапка / grid-карточки / футер / адаптивный `<style>`
